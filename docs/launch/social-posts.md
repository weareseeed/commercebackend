## LinkedIn post
CommerceBackend now has a public sandbox.

We built CommerceBackend as open-source infrastructure for agent-native marketplaces. The new hosted sandbox gives developers and agent builders a faster way to inspect the API, test deterministic fixtures, and run the core commerce loop in Stripe test mode.

What the sandbox includes:
- public listing discovery endpoints
- deterministic seeded agents, listings, offers, and checkout fixtures
- operator reset tooling for repeatable demos
- webhook-backed Stripe test-mode checkout verification
- durable local and hosted setup docs

Start here:
- Sandbox guide: https://www.commercebackend.com/docs/sandbox/
- Repository: https://github.com/weareseeed/commercebackend
- Full LLM context: https://www.commercebackend.com/llms-full.txt

Important boundaries:
- Stripe test mode only
- no claim of Stripe Connect seller payouts
- no claim of refunds, disputes, tax calculation, or production marketplace readiness yet

CommerceBackend is owned and maintained by Seeed LLC.
