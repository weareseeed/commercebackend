Operator Dashboard

Read-only view over GET /v1/operator/metrics: agent, listing, offer, checkout intent, order, and query-log counts, plus critical events. This page issues no mutating requests — sandbox resets and data simulation live elsewhere.

Connection

The operator key is kept only in this tab's sessionStorage for the rest of the browser session — it is never written to localStorage, never committed, and clears when the tab/browser is closed. It is sent as the X-Operator-Key header on each request and nowhere else.
